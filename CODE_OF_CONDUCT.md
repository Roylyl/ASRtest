# Code of conduct

ASRtest contributors are expected to communicate respectfully, discuss technical evidence in good faith, and avoid harassment, threats, discrimination, doxxing, or publication of another person's private data. This applies to repository issues, pull requests, reviews, discussions, and project events.

Project maintainers may edit or remove abusive content and may restrict participation immediately when behavior threatens people, privacy, or the project. For a routine public-thread concern, flag the content and open an issue that links to it. For a sensitive concern, open an issue containing only a request for a private contact channel and no personal details. A maintainer named in a report must not decide that report; another repository collaborator should handle it. Reports should be handled discreetly, fairly, and without retaliation.
