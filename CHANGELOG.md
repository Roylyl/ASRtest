# Changelog

Notable project changes are recorded here.

## Unreleased

- Unified eight local configurations: Zipformer Small; Whisper tiny and base multilingual; Vosk small Chinese and English; SenseVoiceSmall; Paraformer Streaming; and Fun-ASR-Nano.
- Added a shared recording, result, timing, logging, model-information, and settings workflow.
- Added native Liquid Glass UI where supported, with dark mode and reduced-transparency handling.
- Added bundled model manifests, runtime identity checks, local inference smoke tests, and UI navigation checks.
- Prepared original ASRtest materials for release under Apache License 2.0 while retaining separate third-party licenses and model terms.
- Added Git LFS rules, fixed-revision upstream source snapshots, community files, and repository metadata checks.

The complete resource revision remains unpublished while the SenseVoiceSmall
